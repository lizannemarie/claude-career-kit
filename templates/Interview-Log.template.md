# Interview Log: outcomes, status, scheduling, and feedback

Job-search chronology lives here, never in Experience-Context.md: recruiter screens, interview schedules, who was in each round, recaps, feedback, and outcomes. One `##` section per company and role, newest entries at the bottom of each section, each dated.

Format for a new section:

## <Company> — <Role> (<req id if known>)
- YYYY-MM-DD: <event: applied / recruiter screen scheduled / round N with <names> / outcome>
- Prep: links to interviewer profiles, the tailored resume, story ids used.
- Feedback / recap: what went well, what to improve (career facts that come out of this go to /career-update-context for approval).
