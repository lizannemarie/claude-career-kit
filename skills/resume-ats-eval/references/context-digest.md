# Experience Context Digest

Create a compact, session-local digest before scoring. Use the canonical
Experience-Context.md as the primary career-fact source. For story-based
questions or application responses, follow its Detailed Story Index and read
the linked full narrative in Experience-Context-Archive.md before drafting;
the canonical summaries are retrieval cues, not complete stories.

## Digest Fields

- Education and certifications.
- Technical, AI, and cloud experience.
- Named tools and platforms.
- Notable projects and metrics.
- Leadership and team stories.
- Known honest gaps.
- Relevant facts for the current posting.
- Ownership, timeline, metric, and "do not overstate" caveats that attach to each fact.
- Source section and fact identifier.
- Confidence: Confirmed, Partial, or Unverified.

## Selection Rules

1. Return only facts that may support a posting requirement.
2. Include facts already on the resume only when they need to be reframed or verified.
3. Include durable facts that are not present in the selected resume.
4. Do not duplicate facts that are already in the digest.
5. Do not convert a partial or uncertain fact into a confirmed qualification.
6. A digest entry for a story is only a pointer; list the Detailed Story Index link and read the full section before using the story.

## Large-File Rule

If the context file is large, use targeted section searches first. Load the
full canonical file only when a relevant fact cannot be found in the digest
and the clarification path requires it. For stories, targeted-load the linked
archive section even when the summary is already in the digest. Treat the
archive as the detailed story source and historical record; prefer the
canonical file where it resolves an old factual correction or conflict.
